                            BUTTON WIRING DETAIL
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│   Each button connects like this:                                           │
│                                                                              │
│                                                                              │
│        ESP32 GPIO ────┐                                                     │
│                       │                                                      │
│                    ┌──┴──┐                                                  │
│                    │     │  ← Push Button                                   │
│                    └──┬──┘                                                  │
│                       │                                                      │
│        GND Rail ──────┘                                                     │
│                                                                              │
│   When button is pressed:                                                   │
│   - GPIO connects to GND                                                    │
│   - Internal pull-up resistor pulls to HIGH when not pressed               │
│   - Firmware detects LOW when pressed                                       │
│                                                                              │
│   Optional: Add 100nF capacitor across button for debouncing               │
│                                                                              │
│        ESP32 GPIO ────┬─── Button ─── GND                                  │
│                       │                                                      │
│                     [100nF]                                                 │
│                       │                                                      │
│                      GND                                                     │
│                                                                              │

                      POWER SUPPLY RECOMMENDATIONS
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  Option 1: USB Power (Easiest)                                             │
│  ┌─────────┐                                                                │
│  │   USB   │──── ESP32 USB Port                                            │
│  │   5V    │                                                                │
│  └─────────┘                                                                │
│     Provides: ~500mA @ 5V (ESP32 regulates to 3.3V)                        │
│                                                                              │
│  Option 2: External 5V Power                                               │
│  ┌─────────┐                                                                │
│  │   5V    │──── ESP32 VIN Pin                                             │
│  │  Power  │──── GND Pin                                                    │
│  └─────────┘                                                                │
│     Provides: 1A+ @ 5V (ESP32 regulates to 3.3V)                           │
│     Required for: Heavy WiFi usage, SD card writes                          │
│                                                                              │
│  Option 3: Battery (Portable)                                              │
│  ┌─────────┐                                                                │
│  │ Li-Ion  │──── ESP32 VIN Pin (through TP4056 charger)                   │

                           TROUBLESHOOTING TIPS
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  If display doesn't work:                                                   │
│  1. Verify all connections match this diagram                               │
│  2. Check 3.3V power (NOT 5V!) with multimeter                             │
│  3. Ensure CS, DC, RST are connected correctly                              │
│  4. Try different SPI speed (edit User_Setup file)                          │
│                                                                              │
│  If buttons don't work:                                                     │
│  1. Test button continuity with multimeter                                  │
│  2. Verify GPIO pins match this diagram                                     │
│  3. Check for shorts between adjacent pins                                  │
│  4. Add debounce capacitors if getting multiple triggers                    │
│                                                                              │
│  If SD card doesn't work:                                                   │
│  1. Format card as FAT32                                                    │
│  2. Check SPI sharing with display                                          │
│  3. Verify CS pin is unique (GPIO12)                                        │
│  4. Try different card (some cards have compatibility issues)               │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘


                             NOTES AND WARNINGS
╔══════════════════════════════════════════════════════════════════════════════╗
║                                                                              ║
║  ⚠️  IMPORTANT WARNINGS:                                                    ║
║                                                                              ║
║  • ILI9341 requires 3.3V power, NOT 5V!                                    ║
║  • Some ILI9341 modules have voltage regulators, check your datasheet      ║
║  • GPIO36 and GPIO39 are INPUT ONLY - cannot drive outputs                 ║
║  • Avoid GPIO0, GPIO2, GPIO12, GPIO15 as they affect boot mode             ║
║  • SD card must be FAT32 formatted                                          ║
║  • Use quality jumper wires to avoid connection issues                      ║
║                                                                              ║
║  💡 HELPFUL TIPS:                                                           ║
║                                                                              ║
║  • Label all wires for easier troubleshooting                               ║
║  • Test display alone before adding buttons                                 ║
║  • Use breadboard for prototyping, PCB for permanent setup                  ║
║  • Add 100µF capacitor on 3.3V rail for stability                          ║
║  • Keep wires short to reduce noise                                         ║
║  • Document your build with photos                                          ║
║                                                                              ║
